Twilio Voice

UAE number → <Connect><Stream> TwiML. Signed webhooks (X-Twilio-Signature), per-call stream token.

Call session (FastAPI)

20 ms frames → VAD + endpointing → utterances. Barge-in sends clear and keeps only what the caller actually heard in history.

Speech-to-text

Deepgram · Whisper (OpenAI / Groq) with language=ar + business word hints.

LLM receptionist

OpenAI · Anthropic · OpenRouter · Groq · Ollama · mock. Gulf-dialect prompt, one question at a time, read-back before booking.

Booking tools

Split shifts, seats per area (indoor / terrace / family), doctors & services, min. notice, no double booking. Every result carries spoken_* Arabic.

Booking summary

WhatsApp Cloud API template → SMS fallback (Twilio). E.164 from UAE formats; landlines refused.
